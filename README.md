# 地球Online WG

移动端个人成长与日程系统，基于 React、TypeScript 与 Vite。

## 当前范围

- 今日任务与学习副本独立管理
- 任务新增、修改、删除及长按拖动排序
- 日程七日条与月历预览
- 奖励兑换、奖券核销和退款
- 自定义奖励库与奖券管理
- 成长档案、真实累计数据与历史明细
- 新建普通任务和学习副本
- 当前设备本地数据保存

数据保存在当前浏览器设备中。清除浏览器数据会清空记录，跨设备同步将在后续版本实现。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```
